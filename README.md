# Triton スキルアップ

Tritonスクール会員向けの上達記録アプリ（LINEミニアプリ）です。

- 会員：スキルロードマップで「自分でチェック」、認定バッジ、インストラクターのコメント
- インストラクター：レッスン記録、スキルの認定
- 管理者：会員の表示名・プラン・種目・役割の変更

## 構成
- 画面：このリポジトリ（GitHub Pagesで公開）
- ログイン：LINEミニアプリ（LIFF）
- データ：Supabase（`supabase/functions/line-login` がLINEのIDトークンを確認してログイン状態を発行）

`?demo` を付けて開くと、サンプルデータで画面だけ確認できます（保存はされません）。

`config.js` には公開して問題ない値だけを置いています。シークレットやパスワードはここに書かないでください。
